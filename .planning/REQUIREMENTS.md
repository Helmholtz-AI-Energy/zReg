# Requirements: zReg v1.7 Minor Adjustments

**Defined:** 2026-08-01
**Core Value:** Every existing capability works correctly, fails informatively, and is covered by tests.

## v1 Requirements

Requirements for this milestone. Each maps to roadmap phases.

### Ground-Truth Field Consistency

- [ ] **GT-01**: F1 ground truth is drawn from the same `zRegPointCloud` field that `LabelTransferStage` actually transfers (`pc["label"]`), for both `pipeline_mode: paired` and `pipeline_mode: synthetic`
- [ ] **GT-02**: `eval_runner`'s `y_true`/`y_pred` pairing preserves correct per-point correspondence when `transform_spec`'s `dropout_fraction`/`n_new_points` cause source and target point counts to diverge, instead of truncating by position
- [ ] **GT-03**: Existing ground-truth configs (Shah/Kobitski real-data, fully-synthetic ball/bowl label-transfer configs) are audited and updated so label-transfer F1 stays meaningful under the corrected GT-field convention

### Synthetic Labeled Subsample-Pair Generation

- [ ] **GT-04**: User can specify, via YAML config, a synthetic dataset pair generated by subsampling a larger labeled point cloud into two views (source/target) with known per-point correspondence
- [ ] **GT-05**: `DataFactory` exposes a method that generates/retrieves such labeled subsample pairs, building on `generate_training_triple()`'s geometry + `generate_labels()` + `generate_target()` pattern
- [ ] **GT-06**: `EvaluationRunner`/`HyperparamOptimizer` can run label-transfer HPO against subsample-pair-generated ground truth, alongside the existing known-transform (`transform_spec: rigid`/`noise`) mechanism

## Out of Scope

Explicitly excluded. Documented to prevent scope creep.

| Feature | Reason |
|---------|--------|
| Retroactive re-run of all past baseline_experiments results | Out of scope — this milestone fixes the mechanism going forward, not historical run outputs |
| v1.6 Phase 54 (Budget Calibration & Full-Suite Gate) | Deferred, not cancelled — paused while v1.7 is current; resume after v1.7 ships |
