## Tech Debt Summary

### 1. DTW-02: Deferred Metric Interface Requirement (Primary Gap)
DTW-02 was explicitly deferred from Phase 8 and never addressed. DTW functions correctly — this is a consistency improvement, not a functionality gap. Recommend carrying to v1.2.

### 2. Typing Inconsistency in CPD subpackage
`cpd/base.py` and `cpd/_registration.py` use `from typing import Callable` while `dtw/constraints.py` uses `from collections.abc import Callable`. Both are valid Python 3.12; minor consistency issue.

### 3. DistanceMetric Protocol (Documentary Only)
`distances/_protocol.py` defines `DistanceMetric` Protocol for documentation purposes but no consumer imports it as a type annotation. Could be removed or wired up in v1.2.

### 4. Two Residual Silent Exception Handlers
`pairwise_distance_matrix.py:555` catches `FileNotFoundError` after a `Path.exists()` guard (defensive no-op). `transforms.py` catches `AttributeError` for non-torch objects without logging (intentional Open3D fallback). Both are low-risk.

### 5. Intra-Package Import Inconsistency
`color_transfer.py` uses absolute `from zreg.cpd import EstepResult` while all other intra-package imports use relative paths.

### 6. config Module Not Top-Level
`zreg.config` not accessible via `import zreg; zreg.config`. The opt-in design is intentional; only the top-level exposure is missing.

### 7. Nyquist Validation
No VALIDATION.md files for any v1.1 phase. All phases have VERIFICATION.md which is sufficient; Nyquist validation is optional additional assurance.
