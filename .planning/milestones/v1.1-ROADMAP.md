# Milestone v1.1: Code Quality & Refactoring

**Status:** ✅ SHIPPED 2026-05-13

## Milestone Summary

**Inserted Phases:**

- Phase 11.1: Close DTW-02 (inserted 2026-05-13 after milestone audit found DTW-02 deferred gap)

**Key Decisions:**

- Moved CPD/DTW/distances/transforms from flat modules to packages — backwards-compatible import paths preserved via `__init__.py` re-exports
- `compose_constraints` uses variadic args with AND semantics — flexible, no class hierarchy needed
- `DistanceMetric` Protocol is documentary-first — exported for type checking but not enforced at runtime
- Callable pass-through in `_sanitize_pairwise_distance_matrix` — any `Callable[[Tensor, Tensor], Tensor]` accepted directly without special-casing
- No VALIDATION.md files for v1.1 phases — VERIFICATION.md deemed sufficient; Nyquist docs deferred to v1.2

**Issues Resolved:**

- DTW-02 deferred from Phase 8 → closed by Phase 11.1
- Phase 7 VERIFICATION.md missing at first audit → created retroactively 2026-05-13
- 85% downsampling coverage gap → raised to 93% in Phase 11

**Issues Deferred (to v1.2):**

- `typing.Callable` retained in `cpd/base.py` and `cpd/_registration.py` (inconsistent with `collections.abc.Callable` in dtw — both valid in 3.12)
- `DistanceMetric` Protocol not imported by any consumer as a type annotation (documentary only)
- `color_transfer.py` uses absolute intra-package import `from zreg.cpd import EstepResult`
- `config` module not accessible via `import zreg; zreg.config`
- No VALIDATION.md for any v1.1 phase

**Technical Debt Incurred:**

- Two residual `except ... pass` handlers: `pairwise_distance_matrix.py:555` (FileNotFoundError after Path.exists guard) and `transforms.py` (AttributeError for non-torch Open3D fallback)
- Nyquist validation (VALIDATION.md) not performed for any v1.1 phase
