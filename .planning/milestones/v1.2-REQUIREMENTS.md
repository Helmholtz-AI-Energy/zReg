## Out of Scope (carried from active requirements)

| Item | Reason |
|------|--------|
| MLflow / W&B / Neptune | Heavyweight MLOps — local JSON+CSV sufficient for research use |
| pandas | Zero benefit over stdlib csv/json |
| plotly | Matplotlib covers all visualisation needs |
| faiss | sklearn KDTree on CPU correct for kNN consistency |
| Frame/Sequence dataclasses | Duplicate `dict[int, zRegPointCloud]` |
| Monolithic pipeline | Stages must remain independently testable |
| Hardcoded paths | All paths via EvalConfig |
