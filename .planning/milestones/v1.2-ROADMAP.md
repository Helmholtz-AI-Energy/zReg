# Milestone v1.2: Evaluation Framework & Debt Resolution

**Status:** ✅ SHIPPED 2026-06-26
**Phases:** 12–38 (27 phases)
**Total Plans:** 55

## Overview

Delivered a complete, config-driven evaluation framework for the zReg point cloud
pipeline — `EvalConfig` + `DataFactory`, `MetricsEngine` + result types, isolated
pipeline stages (`AlignmentStage` + `LabelTransferStage`), `EvaluationRunner` with
visualisation, a 3-tier `HyperparamOptimizer` (sanity/dev/full via Optuna and
MPI-parallel Propulate), and a `run_eval.py` CLI with scenario configs — all wrapping
existing `zreg.metrics` and `zreg.generators`. Added dual-mode evaluation (paired
source↔target and synthetic transform-spec target generation with GT-aware HPO),
heterogeneous cross-format paired evaluation, CPD-aligned trajectory output with
stored-transform reuse (fixing the 8× scale convergence failure), trajectory export
for LaTeX/pgfplots, a per-frame visualisation refactor, and closed all carry-forward
debt including the codebase-wide `color`→`label` field rename.

## Milestone Summary

**Decimal / inserted phases:** none in v1.2.

**Phase sequencing note:** Phases were executed out of numeric order in places (e.g. 32,
33, 34 before 35; 36/37/38 after 35). All complete and verified.

**Key Decisions:**

- `eval/` is a repo-root namespace directory (no top-level `__init__.py`); test discovery
  via `conftest.py` sys.path insertion. `eval/stages/` and `eval/runners/` are regular packages.
- Result types are frozen pydantic v2 models (`ConfigDict(frozen=True,
  arbitrary_types_allowed=True)`); mutate via `model_copy(update=...)`.
- Two-input stage signatures (`run(source, target, params)`) — DTW never self-aligns.
- Error-at-use-time pattern (load_target/generate_target raise at call time, not construction).
- Stored CPD transform reuse (normalise→apply→denormalise) instead of re-running CPD from
  identity — required to align datasets at different scales.
- `color`→`label` rename with loud failure on missing labels (no silent `id` fallback).
- Propulate is an optional MPI extra (`zreg[propulate]`), lazy-imported; Optuna is the default.

**Issues Resolved:**

- 8× scale convergence failure in aligned-cloud construction (Phase 35, ALIGN-03).
- Self-alignment (`x=y`) in AlignmentStage replaced with true paired source↔target (Phase 30).
- Silent `id` fallback in label-source heuristics (Phase 38, CLN-02).
- D-11 synthetic-mode sanity-isolation regression introduced post-Phase-31 — fixed at
  milestone close (gate pre-populate on `tier != "sanity"`).

**Issues Deferred / Tech Debt:**

- Phase 26 SC-4 (live `mpirun -n 2` Propulate integration) unverified — `propulate` fails
  to import in the dev environment (missing GPy transitive dep). Optuna path unaffected.
- 14 of 27 phases have no VALIDATION.md (Nyquist backfill optional).
- Most SUMMARY.md files have empty `requirements-completed` frontmatter (coverage confirmed
  via VERIFICATION evidence tables instead).
- Open phase-level CR/WR items: matplotlib Agg backend leak; `subprocess.run` timeout in
  `trajectory.py`; `eval/` excluded from `--cov`.
- EXT-01/02/03 were tracked via ROADMAP/STATE/VERIFICATION but not added to REQUIREMENTS.md
  until this archive.
