## Overview

Expanded the alignment and optimization pipeline with 5 alternative methods — all config-driven and backward compatible with existing CPD + grid search workflows. Added ICP (Open3D point-to-point) and Sliced Wasserstein variants as spatial registration alternatives, preprocessing (PCA rotation + velocity landmarks), Sobol quasi-random search as the new default HPO strategy, and per-trajectory data standardization as default data preprocessing.

## Milestone Summary

**Key Decisions:**

- **ICP via Open3D** (not reimplemented): existing `StoredTransform` pattern extended — normalise→ICP→denormalise→cache; zero algorithmic debt
- **Gradient descent for SWD registration**: SO(3) SVD projection every 10 iterations guarantees proper rotation matrix; auto-converts batch dimensions for PyTorch SWD API
- **MaxSWD deferred to v1.5** (Phase 40 checkpoint decision): gradient instability at small batch sizes and compute cost of MC projection; SWD/ASWD/OSWD/GSWD/PSWD fully operational
- **SOBOL_MIN_TRIALS=8 fallback**: module-level constant; below this threshold Sobol degenerates — RandomSearch is a cleaner fallback than a malformed sequence
- **DataPreprocessingConfig defaults live** (not `None`): EvalConfig defaults to `DataPreprocessingConfig()` instance so standardization activates for all users without YAML changes; `None` would require opt-in and create a two-tier API
- **sobol seed/randomize as flat EvalConfig fields** (not nested sub-model): consistency with other flat strategy config; avoids nested YAML migration

**Issues Deferred:**

- **MaxSWD production-readiness**: gradient instability + compute cost → deferred to v1.5 (tracked in Phase 40 PHASE-SUMMARY.md)
- **Advanced ICP variants** (point-to-plane, colored ICP): scope v1.5+
- **GPU-accelerated Sobol sampling**: scipy qmc is CPU-only; no pressure yet
- **Per-dataset or global standardization scopes**: per-trajectory is the scientifically correct unit

**Technical Debt Incurred:**

- Phase 43 REVIEW.md shows IN-01 (test for `robust` method path) and IN-04 (DataFactory integration end-to-end) still open — non-blocking, no production path affected
- Phase 41 `deferred-items.md` lists preprocessing impact on quality metrics (integration test gap) — partially covered by VALIDATION.md
