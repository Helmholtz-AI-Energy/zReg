  <action>
Per D-02: Add zero-range axis guard in `normalize_point_cloud` by clamping `ranges` to `torch.finfo(dtype).eps` before division.

Current buggy code around line 210-213:
```python
# Calculate the range of each dimension
ranges = max_vals - min_vals

# Scale the points
scaled_points = 2 * (points - min_vals) / ranges - 1
```

Change to:
```python
# Calculate the range of each dimension
ranges = max_vals - min_vals

# Guard against zero-range axes (would produce NaN/Inf)
eps = torch.finfo(points.dtype).eps
ranges = torch.clamp(ranges, min=eps)

# Scale the points
scaled_points = 2 * (points - min_vals) / ranges - 1
```

This prevents NaN from division by zero when a point cloud has all identical values along one axis (degenerate/flat case).
  </action>

  </acceptance_criteria>
