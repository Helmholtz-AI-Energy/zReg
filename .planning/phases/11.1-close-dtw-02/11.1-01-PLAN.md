<objective>
Expose `DistanceMetric` as a public Protocol, wire callable pass-through into
`_sanitize_pairwise_distance_matrix`, widen the `distance_metric` type annotation in
`DynamicTimeWarping` and `create_pairwise_distance_matrix`, and cover the new behaviour
with targeted tests.

Purpose: DTW-02 requires all metric variants to share a consistent calling interface.
The Protocol already exists internally but is not exported, and the sanitize function
rejects any non-string argument. Closing the gap means: (1) promoting the Protocol to
the public API, (2) letting callers pass any conforming callable directly, and (3)
updating type hints to reflect the widened contract.

Output: Four modified source files and an expanded test class. No new files created.
</objective>
