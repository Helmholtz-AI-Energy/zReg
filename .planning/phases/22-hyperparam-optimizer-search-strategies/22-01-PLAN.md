class GridSearch:
  search(self, search_space: dict[str, list], objective_fn, warm_start: list[dict] | None = None) -> list[tuple[dict, float]]
  Algorithm (per PATTERNS.md §GridSearch pattern):
    - keys = list(search_space.keys())
    - all_combos = [dict(zip(keys, combo)) for combo in itertools.product(*search_space.values())]
    - Build candidates list with warm_start prepended first, deduplicating via seen: set[tuple] using tuple(sorted(p.items())) as key (per D-04 and PATTERNS.md)
    - Evaluate each candidate: score = objective_fn(params); results.append((params, score))
    - Return results (list[tuple[dict, float]])

--- RandomSearch class ---
class RandomSearch:
  search(self, search_space: dict[str, list], objective_fn, n_trials: int, warm_start: list[dict] | None = None) -> list[tuple[dict, float]]
  Algorithm:
    - Build candidates starting with warm_start (dedup same way as GridSearch), then sample n_trials random combos: for each trial, params = {k: random.choice(v) for k, v in search_space.items()}; use seen set to avoid pure duplicate warm-starts
    - Evaluate each candidate and return list[tuple[dict, float]]
