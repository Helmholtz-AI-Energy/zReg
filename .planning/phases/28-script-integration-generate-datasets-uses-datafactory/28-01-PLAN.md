<objective>
Refactor `scripts/generate_datasets.py` so that all three semi-synthetic
augmentations (noise, scaling, dropout) route through
`DataFactory(EvalConfig(...)).augment(dataset)` instead of the four local
helpers (`_augment_noise`, `_augment_scaling`, `_augment_dropout`,
`apply_augmentation`). Geometry helpers, CSV I/O, and the trajectory
builders are untouched. Closes DF-02.

Purpose: Eliminate the duplicate augmentation implementations in the script;
single source of truth is `eval/data_factory.py` (delivered by Phase 27).
This is a Level 0 refactor — no new logic, no new dependencies. The only
behavioural change is the dropout RNG, which switches from
NumPy `np.random.default_rng(SEED).choice` to PyTorch `torch.randperm`
inside `DataFactory.drop_points`. Dropout CSV content will therefore not
be bit-identical to the pre-refactor version; this divergence is accepted
per D-04/D-05 and explicitly verified differently (statistical parity +
reproducibility) instead of byte parity.

Output: A single modified file plus a transient baseline snapshot used
only for the parity check (the snapshot is deleted before commit).
</objective>
