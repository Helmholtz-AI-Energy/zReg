<objective>
Wire `pipeline_mode = "synthetic"` end-to-end through `EvaluationRunner` and `HyperparamOptimizer`. Consumes the `DataFactory.generate_target()` and `DataFactory.get_synthetic_ground_truth()` methods introduced in Plan 31-01, plus the new `EvalConfig.transform_spec` field. Adds a module-level helper `_apply_transform_to_dataset()` in `eval/runners/optimizer.py` so the sanity tier can produce a local synthetic target without overwriting the main factory's `_synthetic_target` state (D-11 isolation, Pitfall 3).

Purpose: Make `pipeline_mode='synthetic'` produce real behaviour instead of the existing CR-03 placeholder (`target = source`). After this plan, a synthetic-mode EvaluationRunner run produces a transformed target via `generate_target()` and reads GT via `get_synthetic_ground_truth()`; a synthetic-mode HyperparamOptimizer run uses GT F1 as the calibration objective across all three tiers.

Output:
- `eval/runners/eval_runner.py`: replace CR-03 placeholder `else` branch at lines 191–194 with `target = self.factory.generate_target(source, self.config.transform_spec)`; wrap the `gt = self.factory.get_ground_truth(source)` call at line 330 in a `pipeline_mode` branch.
- `eval/runners/optimizer.py`: add module-level `_apply_transform_to_dataset(dataset, transform_spec, config)` helper; wrap the `tier_target` selection at lines 334–337 and the CR-04 `y_true` block at lines 359–369 in `pipeline_mode == "synthetic"` branches (preserving existing paired-mode behaviour in the `else` clauses).
- `tests/test_eval_runner.py`: add `TestEvaluationRunnerSyntheticMode` class verifying `generate_target` and `get_synthetic_ground_truth` are called in synthetic mode.
- `tests/test_optimizer.py`: add `TestOptimizerSyntheticMode` class verifying (a) the sanity tier does NOT call `self._factory.generate_target` (D-11 / Pitfall 3) and (b) dev/full tier uses `_synthetic_target` and `get_synthetic_ground_truth`.
