<objective>
Add Sobol quasi-random search as the default hyperparameter search strategy.

Purpose: Grid search covers the Cartesian product exhaustively but scales poorly; Sobol sequences provide better space-filling coverage with low-discrepancy sampling. Making Sobol the default improves search quality for medium-to-large search spaces without changing the user API.

Output:
- `eval/search_strategies.py` — new `SobolSearch` class + `SOBOL_MIN_TRIALS = 8` constant
- `eval/config.py` — `search_strategy` Literal extended with `"sobol"`, default changed from `"grid"` to `"sobol"`, two new flat fields `sobol_seed` and `sobol_randomize`
- `eval/runners/optimizer.py` — `SobolSearch` imported and wired into the strategy dispatcher
</objective>
