<objective>
Add per-trajectory data standardization as the default preprocessing step in the zReg
evaluation pipeline. A new `DataPreprocessingConfig` Pydantic sub-model (three scaling
methods: z-score, min-max, robust median+IQR) is added to `EvalConfig` and wired into
`DataFactory.load_real()` and `DataFactory.load_target()`. Standardization is applied
per-trajectory (global statistics across all concatenated frames), to the `pos` field
only, after subsampling. Source statistics are cached and reused for the target in paired
mode so both trajectories share the same coordinate space.

Purpose: Ensure alignment algorithms receive consistently scaled input regardless of raw
data range, improving convergence and metric comparability across experiments.

Output:
- `eval/config.py` — `DataPreprocessingConfig` class + `data_preprocessing` field on `EvalConfig`
- `eval/data_factory.py` — `_preprocessing_stats` attribute, `_standardize()` method, wiring
- `tests/test_data_preprocessing_config.py` — Pydantic contract tests
- `tests/test_data_factory.py` — `TestDataPreprocessing` class (unit + integration)
</objective>

  signature is `def _standardize(self, dataset: dict[int, zRegPointCloud], stats: dict | None = None) -> dict[int, zRegPointCloud]:`.
  
  Implementation logic (describe in prose — do not use fenced code):
  
  Guard at top: if `self.config.data_preprocessing is None`, return `dataset` unchanged
  (no-op path; early return by reference).

  Reference `cfg = self.config.data_preprocessing` and `eps = 1e-8`.

  Stats computation branch (when the `stats` argument is None):
  Concatenate every frame's `pos` field into a single tensor by collecting
  `[pc["pos"] for pc in dataset.values()]` and calling `torch.cat(..., dim=0)` to produce
  shape `[total_N, 3]`. Then compute six statistics, each of shape `[3]`:
  - `mean` via `.mean(dim=0)`
  - `std` via `.std(dim=0)` (Bessel-corrected, default in PyTorch)
  - `median` via `torch.quantile(all_pos, 0.5, dim=0)`
  - `q25` and `q75` via `torch.quantile(all_pos, 0.25, dim=0)` and `torch.quantile(all_pos, 0.75, dim=0)`; derive `iqr = q75 - q25`
  - `min_vals` via `.min(dim=0).values`
  - `max_vals` via `.max(dim=0).values`
  Build the stats dict with keys: `"mean"`, `"std"`, `"median"`, `"iqr"`, `"min"`, `"max"`.
  Assign it to `self._preprocessing_stats` AND to the local `stats` variable (so the apply
  step below uses the freshly computed stats).

  When `stats` is provided (not None), use it directly. Do NOT assign to
  `self._preprocessing_stats` in this branch (target reuses source stats by reference; the
  cache is left as set by load_real, per D-03).

  Apply method dispatch: iterate over `dataset.items()` and compute `scaled_pos` per frame:
  - `"standardize"`: `(pos - stats["mean"]) / (stats["std"] + eps)` (D-01, z-score)
  - `"normalize"`: `(pos - stats["min"]) / (stats["max"] - stats["min"] + eps)` (D-02, min-max)
  - `"robust"`: first `(pos - stats["median"]) / (stats["iqr"] + eps)`, then `.clamp(-cfg.robust_outlier_threshold, cfg.robust_outlier_threshold)` (D-02, D-07)

  For each frame, construct a new `zRegPointCloud(pos=scaled_pos, label=pc["label"], id=pc["id"])`,
  then set `result[i]["fps-idx"] = pc["fps-idx"]`. Mirror exactly the construction pattern
  in `self.scale()` (lines 536–543) which does the same pass-through of label, id, and fps-idx.
  Return the new result dict.

  Wire `_standardize` into `load_real()`: after `dataset = self._subsample_to_max(dataset)`,
  insert `dataset = self._standardize(dataset)` before `self._real_dataset = dataset`.

  Wire `_standardize` into `load_target()`: after `dataset = self._subsample_to_max(dataset)`,
  insert `dataset = self._standardize(dataset, stats=self._preprocessing_stats)` before
  `self._target_dataset = dataset`. Passing `self._preprocessing_stats` here handles both
  the paired case (D-03: reuse source stats when not None) and the standalone case
  (D-05: compute own stats when None, since _standardize treats None stats as "compute fresh").

  Add a `logging.debug` call in `_standardize` after stats are determined (either computed or
  received) that logs the method name and the mean tensor values, e.g.:
  `logging.debug("DataFactory._standardize: method=%s mean=%s", cfg.method, stats["mean"])`.
  Add `import logging` to the stdlib imports section at the top of the file (after `import math`,
  before `import random`).
