<objective>
Wire the three existing/new pieces into a seed-driven training-triple pipeline on `DataFactory`,
composing: (1) plan 46-01's `sample_ball()`/`sample_bowl()` for a realistic base cloud, (2) the
existing-but-unwired `generate_labels()` for categorical Voronoi labels, (3) the existing Phase 30
`generate_target()`/`augment()` machinery for exact-correspondence target construction (labels
propagate for free), returning plan 46-02's `TrainingTriple`. Add a seed-level train/val split
(`split_seeds()`, disjoint integer ranges per D-03, NOT `prepare_split()`'s frame-level random
sample). Thread a genuine per-seed RNG through `augment()`'s noise/dropout calls (Pitfall 3) so
diversity across triples is real, not just magnitude-scaled. Provide the Wave-0 test file mandated
by 45-DESIGN.md.

Purpose: this is the deliverable Phase 47's training loop consumes. It resolves D-01 (small regime),
D-02 (on-the-fly seeded, no persisted dataset, no false caching), D-03 (seed-level holdout), and
consumes D-04's samplers.

Output: `split_seeds()`, `DataFactory.generate_training_triple()`, `DataFactory.generate_training_set()`,
per-seed `augment()` threading, and `tests/test_data_factory_training_triples.py`.
</objective>
