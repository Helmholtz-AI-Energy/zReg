<objective>
Lay the foundation for `src/zreg/models/`: declare the previously-undeclared `torch_geometric`
dependency, and build the shared Open3D-wrapped geometry ops (`farthest_point_sample`, `ball_query`,
`build_radius_graph`) that BOTH PointNet++ and eGNN consume. Resolve D-03 (benchmark-first) with an
explicit timing assertion at Phase 46's actual 100-300-point regime.

Purpose: `_ops.py` is the single non-differentiable indexing layer both models depend on; getting it
correct (including the isolated-point guard that prevents intermittent bowl-shape crashes) and
proving it is fast at this scale unblocks all downstream model work without a vectorization detour.
Output: `setup.cfg` dependency line, `src/zreg/models/__init__.py`, `src/zreg/models/_ops.py`,
`tests/test_zreg_models_ops.py`.
</objective>
