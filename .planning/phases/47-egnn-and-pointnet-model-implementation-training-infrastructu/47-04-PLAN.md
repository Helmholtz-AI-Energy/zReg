## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI args → training run | untrusted --model/--device/--epochs/--checkpoint-dir input |
| checkpoint write → Phase 48 read | this phase's save format must not force Phase 48 to weaken weights_only=True |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-47-07 | Tampering / Elevation | checkpoint deserialization (torch.load pickle) | mitigate | Save a plain dict of state_dict + primitives (Pattern 6, no custom classes) so Phase 48's mandated `weights_only=True` load needs no add_safe_globals; round-trip test asserts weights_only load succeeds |
| T-47-08 | Tampering | training against pc["id"] instead of pc["label"] (silently growing class count) | mitigate | Labels read exclusively via TrainingTriple.source_labels/target_labels properties; grep gate asserts no `target_cloud["id"]` access |
| T-47-09 | Denial of Service (silent) | MPS-blind validation masquerading as MPS-tested | mitigate | Local MPS-aware fixture + explicit assert on `.device.type=="mps"`; MPS failure is a loud documented finding, CPU-only hosts skip with an explicit reason (Pitfall 4 / Open Question 2) |
| T-47-10 | Improper Input Validation | CLI --model/--device/--epochs | mitigate | argparse `choices`/int validation at parse time (V5), mirroring EvalConfig field_validator discipline |
