<objective>
Create the mandated Wave-0 joint-cloud conditioning contract test (`test_zreg_models_joint_cloud.py`,
45-DESIGN.md's Downstream Wave-0 Test Obligations table). This is the ONE test file that verifies the
slicing contract for BOTH models uniformly: a joint cloud of `n_source` labeled + `n_target`
unlabeled points must yield exactly `n_target` class-logit rows for the supervised target subset —
not `n_source + n_target`.

Purpose: this contract is the load-bearing invariant of the joint-cloud conditioning adaptation
(45-DESIGN.md Pattern 2) — if a model's output-to-target slicing is wrong, the training loss silently
supervises the wrong rows. Testing both models in one parametrized file matches the mandated file
name and keeps the contract definition single-sourced.
Output: `tests/test_zreg_models_joint_cloud.py`.
</objective>
