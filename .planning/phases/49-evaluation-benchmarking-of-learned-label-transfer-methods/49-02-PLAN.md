<objective>
Build the load-bearing deliverable of Phase 49: the `LabelTransferBenchmark` orchestration class
(`eval/runners/benchmark_runner.py`) that Plan 01's Wave-0-verified Pattern 2 approach unblocks.
It runs all four `LabelTransferStage` methods (`knn_voting`, `cpd_weighted`, `pointnet2`, `egnn`)
against an identical raw source/target pair, computes F1/knn_consistency/latency per method, records
failures gracefully instead of crashing, and covers all four of D-02's evaluation dimensions.

Purpose: Turn the verified Pattern 2 machinery into a reusable comparison runner the user can point
at real trained checkpoints and real data later with zero code changes (D-01's promise).
Output: `LabelTransferBenchmark` class + `save_report`, exported from `eval.runners`, plus a test
suite exercising D-02.1 (F1/knn comparison), D-02.2 (real-data generalization via the Shah CSV
fixture), D-02.3 (latency), D-02.4 (held-out-seed leakage guard), and D-03 (graceful degradation).

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| checkpoint file → process | `.pt` checkpoint deserialized when a learned method runs (via LabelTransferStage, unchanged this phase) |
| config path fields → filesystem | `data_path` / `*_checkpoint_path` read arbitrary local paths (existing EvalConfig trust boundary) |
| method run() exception → benchmark run | a single method's failure could abort the whole comparison |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-49-03 | Denial of Service | one method's `run()` raising ValueError/RuntimeError inside `compare_methods` | mitigate | Per-method `try/except (ValueError, RuntimeError)` records `error=str(e)` and continues; the error-handling test in Task 2 asserts a sibling method still succeeds. |
| T-49-04 | Tampering | `BenchmarkReport.params` → JSON via `save_report` | mitigate | `save_report` uses `report.model_dump()` + `json.dump`; `params` values must stay JSON-primitive; the save_report round-trip test in Task 2 catches any non-primitive field. |
| T-49-05 | Tampering | `.pt` checkpoint deserialization (indirect via LabelTransferStage) | accept | This class never calls `torch.load`; it only calls `LabelTransferStage.run()`, inheriting Phase 48's `weights_only=True` mitigation unchanged. |
| T-49-SC | Tampering | pip installs | accept | Zero new packages this phase; all deps installed in Phases 44-47. No install task, no [ASSUMED]/[SUS] package to gate. |
