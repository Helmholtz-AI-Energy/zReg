<objective>
Make run_all.py rank-aware and add --configs-dir arg so it can be pointed at configs_horeka/ on the cluster.

Purpose: PARA-01 requires HPO trials to execute concurrently via propulate. PARA-02 requires orchestration (file writes, EvaluationRunner, bookkeeping) to execute exactly once regardless of MPI world size. This plan delivers both by (a) adding a top-level MPI RANK guard and (b) adding the --configs-dir arg that lets cluster sbatch scripts swap in the cluster-targeted config tree without touching the local configs/.

Output: Modified baseline_experiments/scripts/run_all.py with MPI import fallback, --configs-dir argparse arg, phase lists built dynamically in main() from that arg, and RANK-0 guards around all non-collective operations.
</objective>
