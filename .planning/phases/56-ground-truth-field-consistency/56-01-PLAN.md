<objective>
Fix the ground-truth field mismatch (GT-01) and the dropout/new-points correspondence
truncation bug (GT-02) in the evaluation framework's ground-truth extraction pipeline.

Purpose: Label-transfer F1 scores are currently computed against `pc["id"]` (a per-point
tracking identity, not a class label) instead of `pc["label"]` (the field
`LabelTransferStage.run()` actually transfers) — and when `transform_spec`'s
`dropout_fraction`/`n_new_points` change point counts between source and target,
`eval_runner._run_single` silently truncates both arrays to `min(len)` by position, scoring
against misaligned points. Both bugs make F1 a meaningless or misleading signal for exactly
the scenarios this framework exists to evaluate.

Output: `EvalConfig.ground_truth_field` (D-01/D-02), a reusable per-frame correspondence-index
mechanism threaded through `DataFactory.drop_points()`/`sample_new_points()` (D-03/D-04,
explicitly designed for reuse by Phase 57), a rewritten `get_ground_truth()` /
`get_synthetic_ground_truth()` that read the configured field and gather by correspondence
instead of truncating, and a re-scoped `eval_runner._run_single` WR-01 fallback.
</objective>

From src/zreg/evaluation/label_transfer.py (compute_f1 — already handles the -1 sentinel this
plan's correspondence gather produces for newly-added points; no change needed to this file):
```
def compute_f1(y_true: torch.Tensor, y_pred: torch.Tensor, average: str = "weighted",
                zero_division: int = 0) -> float
```
Sentinel masking: `mask = y_true != -1`; entries where `y_true == -1` are excluded from the
score before delegating to `sklearn.metrics.f1_score`. Requires `y_true.shape[0] ==
y_pred.shape[0]` (raises `ValueError` otherwise) — this is exactly why GT-02's gather-based fix
must produce a `y_true` already sized to match `y_pred`'s (target's) point count per frame.

From eval/types.py (AlignResult.estep_results — the established codebase precedent this plan's
`_correspondence_idx` design follows: "per-frame `torch.Tensor` dict keyed by frame index,
exposed as diagnostic/tracking state", `dict[int, EstepResult] = Field(default_factory=dict)`).
