<objective>
Add a new `DataFactory` method, `generate_subsample_pair()`, that generates a labeled
`(source, target)` dataset pair by subsampling a larger labeled point cloud into two
independently-dropped views with tracked per-point correspondence — a sibling mechanism to
the existing known-transform (`transform_spec: rigid`/`noise`) path built in Phase 31/56.

Purpose: GT-04/GT-05 require a config-driven synthetic labeled subsample-pair generation
mechanism that (a) works against real data already loaded via `load_real()`/`load_target()`,
not just fresh ball/bowl geometry, and (b) still supports the fully-synthetic "no real data
available" case as a second mode — while remaining compatible with the existing
`get_synthetic_ground_truth()` GT-extraction consumer so downstream wiring (Plan 57-02/57-03)
needs no changes to that method.

Output: `DataFactory.generate_subsample_pair(dataset, transform_spec)` returning
`tuple[dict[int, zRegPointCloud], dict[int, zRegPointCloud]]`, a new
`self._subsample_source_view` instance attribute, and an `eval/config.py` docstring update
documenting the new `transform_spec["type"] == "subsample_pair"` discriminator value (no
schema change — D-04).
</objective>

From eval/data_factory.py (current state, all pre-existing — this plan's new method composes
these, does not modify their bodies except where explicitly noted):

`drop_points(self, dataset, fraction, seed=42) -> dict[int, zRegPointCloud]` — removes
`fraction` of points per frame via `torch.randperm(...)[:keep].sort().values`; when
`self._correspondence_idx` is already non-`None` for a given frame key, COMPOSES with it
(`new_corr[i] = self._correspondence_idx[i][idx]`) rather than starting fresh; only falls back to
`idx.clone()` when no prior correspondence exists for that key. `self._correspondence_idx =
new_corr` is the LAST statement before `return`. Calling this twice in a row on `self` WITHOUT
resetting `self._correspondence_idx = None` in between is a correctness bug, not just a
capture-timing risk: the second call's `idx` is computed over the FULL input `dataset` range, but
it gets used to index the FIRST call's (already-reduced-length) correspondence tensor, raising
`IndexError`. Calling this twice in a row on `self` therefore requires (a) resetting
`self._correspondence_idx = None` immediately before EACH call, and (b) capturing
`self._correspondence_idx` into a local variable immediately after each call, before the next
call's reset clears it.

`generate_target(self, dataset, transform_spec) -> dict[int, zRegPointCloud]` — strips
`transform_spec["type"]`, saves/restores `self.config.augmentation_params` in `try/finally`,
sets `self._correspondence_idx = None` at the START (before `try:`), then after a successful
`augment()` call sets `self._synthetic_target = result`, `self._source_dataset = dataset` (the
method's OWN `dataset` argument — not the phase-57 base dataset), `self._transform_spec =
transform_spec`. Calling `generate_target()` on an already-subsampled `target_view` therefore
OVERWRITES `self._source_dataset`/`self._correspondence_idx` with values that are wrong for
this phase's base-dataset GT contract — the new method must restore the correct values
immediately after any `generate_target()` call it makes internally.

`generate_training_triple(self, seed, n_classes=6, shape=None, n_points=None) -> TrainingTriple`
(lines 348-439) — the synthesize-from-scratch geometry pattern to mirror (NOT call directly —
`generate_training_triple` returns a frozen `TrainingTriple`, not a `dict[int, zRegPointCloud]`
tuple, and this plan's method must NOT modify or wrap it). Its exact geometry dispatch:
`rng = random.Random(seed)`; `n_points = rng.randint(100, 300)` when `None`; `shape = "ball" if
seed % 2 == 0 else "bowl"` when `None`; `pos = sample_ball(n_points, seed=seed)` or
`sample_bowl(n_points, seed=seed)`; `base = {0: zRegPointCloud(pos=pos)}`; `source =
generate_labels(base, n_classes=n_classes, seed=seed)`.

`get_synthetic_ground_truth(self) -> dict[int, torch.Tensor]` (lines 678-767) — the consumer
contract this plan's method must satisfy WITHOUT modification: reads
`pc[self.config.ground_truth_field]` from `self._source_dataset.items()`; when
`self._correspondence_idx is not None and k in self._correspondence_idx`, gathers by that
correspondence (`corr = self._correspondence_idx[k]`; `-1` sentinel for `corr < 0` entries);
raises `RuntimeError` if `self._synthetic_target is None`.

`DataFactory.__init__` (lines 117-155) — existing `None`-initialized instance-attribute
convention: `self._synthetic_target`, `self._source_dataset`, `self._transform_spec`,
`self._correspondence_idx` (Phase 56). This plan adds `self._subsample_source_view` to the
same block.
