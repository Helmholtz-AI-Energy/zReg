<objective>
Wire `EvaluationRunner.run()` to dispatch to Plan 57-01's `DataFactory.generate_subsample_pair()`
when `config.transform_spec["type"] == "subsample_pair"`, as a sibling branch alongside the
existing `pipeline_mode == "paired"` / `type: rigid`/`noise` `generate_target()` paths.

Purpose: GT-06 requires `EvaluationRunner` to run a full evaluation end-to-end against
subsample-pair-generated ground truth. The current `run()` eagerly calls `factory.load_real()`
before deciding how to build `target` (PATTERNS.md finding) — this must change so that
`generate_subsample_pair()`'s "synthesize" mode (no real data required, D-02) is actually
reachable, and so BOTH `source` and `target` come from the pair-generation method rather than
`source` being the raw loaded dataset and only `target` being transformed from it.

Output: A modified `EvaluationRunner.run()` dispatch block and a new
`TestEvaluationRunnerSubsamplePair` test class proving the wiring, non-regression of the
existing `rigid`/`noise` and `paired` paths, and non-degenerate end-to-end F1.
</objective>
