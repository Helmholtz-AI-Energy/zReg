<objective>
Layer D-07's opt-in multi-seed averaging on top of Plan 58-03's single-seed `subsample_pair`
wiring: when `transform_spec["seed"]` is a list of ints, average a trial's score across the N
resulting subsample pairs, gated to the `full` tier so sanity/dev tiers never silently pay the
N-seed cost.

Purpose: GT-04/GT-06's config surface locks D-07 as part of this phase's scope (only D-08's
train/val split is deferred). D-06 states this is a HARD constraint: "no changes needed inside
`_objective` for the default path." This plan honors that literally — every line Plan 58-03
wrote for the default (single int seed) path stays untouched; D-07's list-seed handling lives
entirely in new, additive code (`_resolve_subsample_pair_seeds`, a new
`_score_subsample_pair_multiseed` method, and a small guard added to `run()`'s pre-populate
step to skip pre-populating a single target when no single target exists to pre-populate).

Output: `SUBSAMPLE_PAIR_MULTISEED_TIER` module constant, `_resolve_subsample_pair_seeds()`
module-level helper, `HyperparamOptimizer._score_subsample_pair_multiseed()` method, a small
list-seed guard in `run()`'s pre-populate step, and a new `TestSubsamplePairMultiseed` test
class.
</objective>
