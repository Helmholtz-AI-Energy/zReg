# Quick Task 260728-q01: Add EGNN + POINTNET2 to LabelTransferMethod

## Background

`label_transfer.py` had four geometry-based methods (NEAREST_NEIGHBOR, CPD_WEIGHTED,
KNN_VOTING, GAUSSIAN_KERNEL). The neural-network models in `src/zreg/models/` provide
a more powerful transfer approach but were completely disconnected from the standard
interface. This fix makes `label_transfer` the single entry point for all transfer
strategies.

## Model interface (verified from source)

Both `EGNNLabelTransfer` and `PointNet2LabelTransfer` share the same forward signature:

```
forward(joint_pos: Tensor[n_joint, 3], joint_feat: Tensor[n_joint, n_classes+1])
    -> Tensor[n_joint, n_classes]   # per-point logits
```

`joint_feat` encoding:
- source rows: one-hot label (dims 0..n_classes-1) + unknown_flag=0 (dim n_classes)
- target rows: zeros (dims 0..n_classes-1) + unknown_flag=1 (dim n_classes)

Return convention: caller slices `logits[n_source:]` to get target-only predictions.
The dispatcher returns softmax probabilities (shape `[n_target, n_classes]`) for
consistency with CPD_WEIGHTED and GAUSSIAN_KERNEL which also return soft assignments.

### 1e. Add _transfer_labels_model() private function

```python
def _transfer_labels_model(
    source_pos: torch.Tensor,
    target_pos: torch.Tensor,
    source_colors: torch.Tensor,
    model: "nn.Module",
) -> torch.Tensor:
    """Transfer labels using a pre-trained neural network (EGNN or PointNet2).

    Builds a joint source+target cloud, encodes source labels as one-hot features
    with unknown_flag=0, encodes target points as unknown_flag=1, and runs
    model.forward(). Returns softmax probabilities for target points only.
    """
    n_source = source_pos.shape[0]
    n_classes = source_colors.shape[1]

    joint_pos = torch.cat([source_pos, target_pos], dim=0)

    # joint_feat: [n_joint, n_classes + 1]
    # source rows: source_colors (one-hot / soft) + unknown_flag=0
    # target rows: zeros + unknown_flag=1
    joint_feat = torch.zeros(
        joint_pos.shape[0], n_classes + 1,
        dtype=torch.float32, device=source_pos.device
    )
    joint_feat[:n_source, :n_classes] = source_colors.float()
    joint_feat[n_source:, n_classes] = 1.0

    model.eval()
    with torch.no_grad():
        logits = model(joint_pos, joint_feat)  # [n_joint, n_classes]

    target_logits = logits[n_source:]
    return torch.softmax(target_logits, dim=-1)
```

    n_source = source["pos"].shape[0]
    n_classes = source["label"].shape[1]

        captured["joint_pos"] = joint_pos
        captured["joint_feat"] = joint_feat

        jf[:n_source, :n_classes],
